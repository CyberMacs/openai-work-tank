# Kiegészítő utasítások

A program használja a Codex Desktop telepítésével együtt érkező helyi `codex.exe` fájlt, ezért külön Codex CLI telepítés nem szükséges, ha a Codex Desktop telepítve van és a felhasználó be van jelentkezve.

A tálcaikonon a konkrét fennmaradó heti százalék nagy számjegyekkel jelenik meg, kis robotjelvénnyel. A Windows 11 rendszerterületére alkalmazás nem helyezhet el az óra mellé önálló, széles szövegcímkét; az érték ezért a négyzetes tálcaikonban látszik. A részletablak a jobb alsó tálca mellé nyílik, az egér-fölötti szöveg pedig tartalmazza a reset idejét.
