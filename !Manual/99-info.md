# Fontos tudnivalók

A program nem kér és nem tárol OpenAI API-kulcsot, jelszót vagy ChatGPT-sütit. Nem használ böngésző-scrapinget, távoli szervert vagy telemetriát. Kizárólag a helyi Codex CLI már meglévő hitelesítését használja.
