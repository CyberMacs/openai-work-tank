# Telepítés

1. Másold át a `Final\OpenAIWorkTank-Setup.exe` fájlt a másik Windows 10 vagy 11 gépre.
2. Előbb legyen azon a gépen telepítve a Codex CLI, és a felhasználó legyen belépve a ChatGPT-fiókjába.
3. Indítsd el a telepítőt. Nem kér rendszergazdai jogot.
4. A program az aktuális felhasználó saját helyi alkalmazásadat-mappájába települ, majd azonnal elindul.
5. Az automatikus indulást a telepítő bekapcsolja. A tálcaikon jobb gombos menüjében ki- vagy bekapcsolható.

## Letöltés GitHubról
1. Nyisd meg: https://github.com/CyberMacs/openai-work-tank/releases/tag/v0.1.2
2. A **Assets** részből töltsd le az OpenAIWorkTank-Setup-v0.1.2.exe fájlt.
3. Indítsd el a letöltött telepítőt, majd kövesd az ablak lépéseit.
4. A telepítő beállítja az automatikus indítást is. A program ezután az értesítési területen jelenik meg.
