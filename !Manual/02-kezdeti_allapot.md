# Kiindulási állapot

Új projekt készült. A helyi gépen .NET 8.0.415, Windows Desktop Runtime és Codex CLI 0.155.0-alpha.9.2 volt elérhető. A Codex App Server helyi JSON-sémája a projekt `schemas` mappájába került.

A program csak helyi Codex App Servert használ. A heti ablakot kizárólag a 10080 perces időtartam alapján azonosítja; az 5 órás értéket nem helyettesíti vele.
